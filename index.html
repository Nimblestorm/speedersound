Speeder setup

  1. Share, then Add to Home Screen, then open it from there.
  2. Make sure the phone is not on Silent (ring switch or Action button).
  3. Allow Location while using, with Precise on.
  4. Allow Motion when asked. Set Auto-Lock to Never while riding.

While the engine is on, other apps' audio pauses, like a music app.

Open from the Home Screen icon for full screen and screen-lock protection.
